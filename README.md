# AppShowcase - Application Advertisement Website

A modern, responsive HTML and CSS website template for advertising applications. Perfect for showcasing your app's features, pricing, and getting customer inquiries.

## Features

✨ **Modern Design**
- Clean and professional interface
- Gradient color scheme with blue theme
- Smooth animations and hover effects

📱 **Fully Responsive**
- Mobile-friendly design
- Works seamlessly on desktop, tablet, and mobile devices
- Responsive grid layouts

🎨 **Pure HTML & CSS**
- No JavaScript dependencies
- Lightweight and fast loading
- Easy to customize and maintain

## Sections Included

1. **Navigation Bar** - Sticky navbar with smooth scrolling links
2. **Hero Section** - Eye-catching banner with call-to-action buttons
3. **Features** - Grid showcase of 6 key features with icons
4. **About Section** - Information about why customers should choose your app
5. **Pricing** - Three-tier pricing table with popular plan highlighted
6. **Contact** - Contact information and message form
7. **Footer** - Links and copyright information

## How to Use

1. **Download/Clone** the files to your local machine
2. **Open** `index.html` in your web browser
3. **Customize** the content with your app information:
   - Replace "AppShowcase" with your app name
   - Update feature descriptions and icons
   - Modify pricing and plans
   - Add your contact information

## Customization Guide

### Colors
The primary color is **#0066cc** (blue). To change the theme:
1. Open `styles.css`
2. Find and replace all occurrences of `#0066cc` and `#0052a3`
3. Update button and link colors to match your brand

### Content Changes
- **App Name**: Update "AppShowcase" in HTML navbar and footer
- **Features**: Modify feature cards in the Features section
- **Pricing**: Edit pricing plans and features list
- **Contact**: Update email, phone, and address information

### Font & Typography
The site uses 'Segoe UI' font. To change:
- Open `styles.css`
- Find `font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;`
- Replace with your preferred font

## Features of the CSS

- **Smooth Scrolling**: `scroll-behavior: smooth;`
- **Sticky Navigation**: Navigation stays at top while scrolling
- **Hover Effects**: Cards lift up on hover with box shadows
- **Focus States**: Form inputs have blue highlight on focus
- **Transitions**: Smooth color and transform transitions
